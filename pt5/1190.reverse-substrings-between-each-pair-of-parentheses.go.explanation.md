# 1190. Reverse Substrings Between Each Pair Of Parentheses - Go

## Go implementation notes
A `[]byte` stack is used because the string contains ASCII lowercase letters and parentheses.

## Go interview framing
In Go, explain both the algorithmic invariant and the concrete representation: slices for dense arrays/queues/stacks, maps for sparse lookup, structs for queue states or records, and channels or `sync` primitives for concurrency. Then walk through how the code mutates that representation while preserving the invariant.

## Core idea
Use a stack. When a closing parenthesis appears, pop back to the matching opening parenthesis; the popped characters are already in reversed order.

## Algorithm
1. Push normal characters and opening parentheses onto the stack.
2. On `)`, pop characters into a temporary list until `(` is found.
3. Discard the `(` and extend the stack with the popped characters.
4. Join the stack after processing all characters.

## Data structure choice
The stack models nested parentheses: inner groups are resolved before outer groups.

## Correctness argument
The top of the stack since the latest `(` is exactly the innermost substring. Popping it reverses its order, and replacing the parenthesized section with that reversal matches the required innermost-first process.

## Complexity
For `n <= 2000`, stack reversal is easily accepted. Worst-case time can be `O(n^2)` with deep nesting; space is `O(n)`.

## Tests and edge cases
- `(abcd)` returns `dcba`.
- Nested sample `(u(love)i)` returns `iloveu`.
- Strings without parentheses return unchanged.

## Possible improvements
The current solution is chosen for clarity and interview reliability. If constraints were much larger, the main improvement would be to reduce the stated bottleneck in the complexity section, while keeping the same correctness invariant.
