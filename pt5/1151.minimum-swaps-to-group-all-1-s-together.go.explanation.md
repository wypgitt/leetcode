# 1151. Minimum Swaps To Group All 1s Together - Go

## Go implementation notes
The Go implementation uses a fixed-length sliding window over the `[]int` data slice.

## Go interview framing

## Core idea
If there are `k` ones, the final grouped block has length `k`. Minimize zeros inside any length-`k` window, because each such zero must be swapped with a one outside.

## Algorithm
1. Count total ones `k`.
2. Compute zeros in the first window of length `k`.
3. Slide the window and update zero count as one element enters and one leaves.
4. Return the minimum zero count seen.

## Data structure choice
A sliding window maintains the current candidate block.

## Correctness argument
Any valid final arrangement corresponds to choosing a length-`k` segment that will contain all ones. The number of swaps needed for that segment equals its number of zeros. Minimizing over all segments yields the answer.

## Complexity
Time is `O(n)` and space is `O(1)`.

## Tests and edge cases
- No ones or one one returns `0`.
- Already grouped ones return `0`.
- Alternating arrays test the sliding update.

## Possible improvements
The current solution is chosen for clarity and interview reliability. If constraints were much larger, the main improvement would be to reduce the stated bottleneck in the complexity section, while keeping the same correctness invariant.
