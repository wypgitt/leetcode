# 1120. Maximum Average Subtree - Java

## Java implementation notes
The recursive helper returns an `int[]` pair `[sum, count]`. A field `best` tracks the maximum `double` average.

## Core idea
A subtree average needs its sum and node count, so compute those bottom-up with DFS and update the best average at every node.

## Algorithm
1. For a null child, return sum `0` and count `0`.
2. For each node, recursively get left and right sums/counts.
3. Compute this subtree's total sum and count, update the global maximum average, and return the pair upward.

## Data structure choice
No external data structure is needed beyond recursion; each stack frame carries a `(sum, count)` pair.

## Correctness argument
Every subtree is rooted at exactly one node. When DFS visits that node, it has already computed all descendants, so its average is exact and considered once. The maximum over all considered nodes is therefore the answer.

## Complexity
Time is `O(n)`. Recursion space is `O(h)`, `O(n)` in a skewed tree.

## Tests and edge cases
- A single node returns its value.
- Leaves can be the maximum average.
- Zero-valued nodes are handled because sums and counts are explicit.

## Possible improvements
The current solution is chosen for clarity and interview reliability. If constraints were much larger, the main improvement would be to reduce the stated bottleneck in the complexity section, while keeping the same correctness invariant.
