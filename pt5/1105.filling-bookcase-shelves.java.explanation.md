# 1105. Filling Bookcase Shelves - Java

## Java implementation notes
A one-dimensional `int[] dp` is the central Java data structure. `Arrays.fill` initializes unreachable states, and the nested backward scan evaluates every valid last shelf.

## Core idea
Use dynamic programming where `dp[i]` is the minimum height needed for the first `i` books. The last shelf can contain some suffix of those books, so try every valid suffix.

## Algorithm
1. Initialize `dp[0] = 0` and all other states to infinity.
2. For each ending position `i`, scan books backward while the shelf width remains valid.
3. Maintain the total width and maximum height of this candidate last shelf.
4. Update `dp[i]` with `dp[j] + shelf_height`, where books `j..i-1` sit on the last shelf.

## Data structure choice
A one-dimensional DP array is enough because the only decision boundary is the index where the current shelf starts.

## Correctness argument
In any optimal arrangement for the first `i` books, the final shelf contains a contiguous suffix because book order cannot change. The algorithm enumerates every possible suffix that fits, combines it with the optimal arrangement of the prefix, and takes the minimum, so by induction every `dp[i]` is optimal.

## Complexity
The backward scan can inspect up to `n` books for each `i`, so time is `O(n^2)`. Space is `O(n)`.

## Tests and edge cases
- The sample `[[1,1],[2,3],...]` with width `4` returns `6`.
- A single book returns its height.
- When all books fit on one shelf, the answer is the maximum height.

## Possible improvements
The current solution is chosen for clarity and interview reliability. If constraints were much larger, the main improvement would be to reduce the stated bottleneck in the complexity section, while keeping the same correctness invariant.
