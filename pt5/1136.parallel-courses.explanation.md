# 1136. Parallel Courses

## Core idea
Courses with no remaining prerequisites can be taken in the current semester. This is topological sorting by BFS levels.

## Algorithm
1. Build adjacency lists and indegree counts.
2. Initialize the queue with all courses whose indegree is zero.
3. Each BFS layer is one semester; remove all currently available courses.
4. Decrement indegrees of dependent courses and enqueue newly available ones.
5. If all courses are taken, return semester count; otherwise a cycle exists.

## Data structure choice
A queue stores available courses; indegree counts represent unmet prerequisites.

## Correctness argument
A course is enqueued exactly when every prerequisite has been taken, so every semester schedule is valid. Taking all currently available courses is optimal because delaying an available course cannot unlock future courses earlier.

## Complexity
Time is `O(n + m)` and space is `O(n + m)`.

## Interview explanation
Start by naming the invariant: what state is being stored and why that state is sufficient. Then explain the transition or traversal in the same order the code executes. Finally, connect the stopping condition to the returned value. This keeps the explanation grounded in the code instead of sounding like a memorized trick.

## Tests and edge cases
- No prerequisites returns `1` for all courses taken together.
- A chain of prerequisites returns chain length.
- A cycle leaves courses untaken and returns `-1`.

## Possible improvements
The current solution is chosen for clarity and interview reliability. If constraints were much larger, the main improvement would be to reduce the stated bottleneck in the complexity section, while keeping the same correctness invariant.
