# 1171. Remove Zero Sum Consecutive Nodes From Linked List - Java

## Java implementation notes
A `HashMap<Integer, ListNode>` maps prefix sums to the last node with that sum, then pointer rewiring removes zero-sum ranges.

## Core idea
Prefix sums identify zero-sum ranges: if two nodes have the same prefix sum, everything between them sums to zero.

## Algorithm
1. Add a dummy node before the head.
2. First pass maps each prefix sum to the last node with that prefix.
3. Second pass recomputes prefix sums and jumps `node.next` to the node after the last occurrence of the same prefix.
4. Return `dummy.next`.

## Data structure choice
A hash map from prefix sum to node gives direct access to the farthest removable range.

## Correctness argument
Equal prefix sums mean the intervening list segment sums to zero. Using the last occurrence removes the longest such segment from each prefix, which also removes nested zero-sum segments in one second pass.

## Complexity
Two passes over the list: `O(n)` time and `O(n)` space.

## Tests and edge cases
- A zero-sum prefix is removed because of the dummy node.
- Nested ranges like `[1,2,-3,3,1]` are handled.
- No zero-sum segment returns the original list.

## Possible improvements
The current solution is chosen for clarity and interview reliability. If constraints were much larger, the main improvement would be to reduce the stated bottleneck in the complexity section, while keeping the same correctness invariant.
