# 1162. As Far From Land As Possible - Java

## Java implementation notes
Multi-source BFS starts from all land cells in an `ArrayDeque<int[]>`, and the grid itself marks visited water.

## Core idea
Run multi-source BFS from all land cells. The last water layer reached has the maximum distance to land.

## Algorithm
1. Push every land cell into the BFS queue.
2. If the grid is all land or all water, return `-1`.
3. Expand in four directions, converting newly reached water to land to mark visited.
4. Count BFS layers; the final layer distance is the answer.

## Data structure choice
A queue supports BFS from many sources at once. The grid itself marks visited cells.

## Correctness argument
Multi-source BFS reaches each water cell by the shortest path from any land cell. Therefore the maximum layer number among reached water cells is exactly the farthest nearest-land distance.

## Complexity
Each cell is enqueued at most once: `O(n^2)` time and `O(n^2)` space in the worst case.

## Tests and edge cases
- All land returns `-1`.
- All water returns `-1`.
- A land cell in the center produces symmetric distance layers.

## Possible improvements
The current solution is chosen for clarity and interview reliability. If constraints were much larger, the main improvement would be to reduce the stated bottleneck in the complexity section, while keeping the same correctness invariant.
