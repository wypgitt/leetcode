# 1170. Compare Strings By Frequency Of The Smallest Character - Java

## Java implementation notes
Word frequencies are sorted in an `int[]`; a hand-written upper-bound binary search counts strictly greater values.

## Core idea
Precompute and sort the frequency value for every word. Each query asks how many word frequencies are greater than its frequency.

## Algorithm
1. Define `f(s)` as count of the lexicographically smallest character in `s`.
2. Compute all `f(word)` values and sort them.
3. For each query, use `bisect_right` to find the first word frequency greater than `f(query)`.
4. Subtract that position from the number of words.

## Data structure choice
A sorted array plus binary search avoids scanning every word for every query.

## Correctness argument
Because word frequencies are sorted, all values after `bisect_right(freq)` are exactly those strictly greater than the query frequency. Counting that suffix answers the query.

## Complexity
Preprocessing is `O(W*L + W log W)`. Each query is `O(Q_L + log W)`. Space is `O(W)`.

## Tests and edge cases
- Strict comparison means equal frequencies are not counted.
- Single-character words have frequency `1`.
- Repeated smallest letters such as `aaab` test `f` calculation.

## Possible improvements
The current solution is chosen for clarity and interview reliability. If constraints were much larger, the main improvement would be to reduce the stated bottleneck in the complexity section, while keeping the same correctness invariant.
