# 1131. Maximum Of Absolute Value Expression

## Core idea
Remove absolute values by enumerating sign choices. For each sign pattern, maximize the difference between transformed values at two indices.

## Algorithm
1. The expression is `|a_i-a_j| + |b_i-b_j| + |i-j|`.
2. For each `sign1` and `sign2` in `{1,-1}`, compute `sign1*arr1[i] + sign2*arr2[i] + i`.
3. The best pair for that sign pattern is `max(value) - min(value)`.
4. Take the maximum over all four patterns.

## Data structure choice
Only running minima and maxima are required.

## Correctness argument
Every absolute-value expression can be represented by choosing signs for the two array differences and the index difference. Considering all sign combinations ensures the maximizing pair's sign pattern is included, and max-min gives the best pair for that linear form.

## Complexity
Four linear scans: `O(n)` time and `O(1)` space.

## Interview explanation
Start by naming the invariant: what state is being stored and why that state is sufficient. Then explain the transition or traversal in the same order the code executes. Finally, connect the stopping condition to the returned value. This keeps the explanation grounded in the code instead of sounding like a memorized trick.

## Tests and edge cases
- Works with negative numbers because signs are explicit.
- Arrays of length two compare the only pair.
- Equal values produce distance from index difference only.

## Possible improvements
The current solution is chosen for clarity and interview reliability. If constraints were much larger, the main improvement would be to reduce the stated bottleneck in the complexity section, while keeping the same correctness invariant.
