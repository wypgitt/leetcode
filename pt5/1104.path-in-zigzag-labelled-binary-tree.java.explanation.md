# 1104. Path In Zigzag Labelled Binary Tree - Java

## Java implementation notes
The Java solution uses an `ArrayList<Integer>` for the path and `Integer.highestOneBit` to identify the current level range. `Collections.reverse` turns the collected node-to-root path into root-to-node order.

## Core idea
Walk from the target label back to the root. At each level, mirror the zigzag label into the normal left-to-right label, divide by two to get the parent, and continue.

## Algorithm
1. The binary length of `label` tells us its level because level `d` contains labels `[2^(d-1), 2^d - 1]`.
2. For a zigzag row, the mirrored value in normal order is `level_start + level_end - label`.
3. The parent in the normal tree is that mirrored value divided by two. The formula `(level_start + level_end - label) // 2` gives the parent label as it appears on the previous zigzag row.
4. Collect labels while moving upward, then reverse the list.

## Data structure choice
Only an output list is required. The tree is implicit, so building nodes would waste memory.

## Correctness argument
Every step computes the unique parent of the current node in the underlying perfect binary tree, accounting for whether the current row is reversed. Repeating this until label zero reaches exactly the root path, and reversing changes the order from node-to-root into root-to-node.

## Complexity
There are `O(log label)` levels. Time is `O(log label)` and extra space is `O(log label)` for the returned path.

## Tests and edge cases
- `label = 14` gives `[1, 3, 4, 14]`.
- `label = 1` returns `[1]`.
- Even-level targets such as `26` verify the mirror arithmetic.
