# 1198. Find Smallest Common Element In All Rows - Java

## Java implementation notes
A `HashMap<Integer, Integer>` counts row appearances. Strictly increasing rows make each value appear at most once per row.

## Core idea
Rows are strictly increasing, so each row contributes each value at most once. Count in how many rows each value appears, then scan the first row for the smallest common value.

## Algorithm
1. Use a `Counter` and update it with every row.
2. Because rows have no duplicates, the count for a value equals the number of rows containing it.
3. Scan `mat[0]` in sorted order and return the first value whose count equals the row count.
4. Return `-1` if none exists.

## Data structure choice
A counter maps values to row occurrence counts.

## Correctness argument
A common element must appear in the first row. Since that row is sorted, the first first-row value with count equal to `m` is the smallest value appearing in every row.

## Complexity
Time is `O(mn)`, space is `O(number of distinct values)`.

## Tests and edge cases
- Sample matrix returns `5`.
- If the first common element is the first column value, it returns immediately.
- No common value returns `-1`.
