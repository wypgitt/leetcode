# 1161. Maximum Level Sum Of A Binary Tree - Java

## Java implementation notes
An `ArrayDeque<TreeNode>` performs level-order traversal. Strict comparison keeps the smallest level on ties.

## Core idea
Level-order traversal naturally groups nodes by level. Track the level sum and keep the first level with the maximum sum.

## Algorithm
1. Start BFS with the root at level one.
2. For each queue layer, sum all node values in that layer.
3. Append children for the next layer.
4. Update the best only when the new sum is strictly larger, preserving the smallest level on ties.

## Data structure choice
A queue stores the current BFS frontier.

## Correctness argument
BFS processes exactly one tree level per outer loop iteration. Since every level sum is computed exactly once and strict comparison preserves earlier ties, the returned level matches the required smallest maximum-sum level.

## Complexity
Time is `O(n)`, space is `O(w)` where `w` is maximum tree width.

## Tests and edge cases
- Negative values require initializing best to negative infinity.
- Single root returns level `1`.
- Tie sums keep the earlier level.

The current solution is chosen for clarity and interview reliability. If constraints were much larger, the main improvement would be to reduce the stated bottleneck in the complexity section, while keeping the same correctness invariant.
