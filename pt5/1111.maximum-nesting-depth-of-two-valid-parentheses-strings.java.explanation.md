# 1111. Maximum Nesting Depth of Two Valid Parentheses Strings - Java

## Core idea
Assign parentheses by depth parity. Alternating depths between the two groups splits the maximum nesting roughly in half.

## Algorithm
1. Track the current nesting depth.
2. For an opening parenthesis, increment depth first, then assign `depth % 2`.
3. For a closing parenthesis, assign the current `depth % 2`, then decrement depth.
4. Matching open and close parentheses receive the same group because they are seen at the same depth.

## Data structure choice
A result array and an integer depth counter are sufficient.

## Correctness argument
Each matched pair is assigned consistently, so both subsequences remain valid parentheses strings. Depths alternate between groups, which prevents either group from receiving two adjacent nesting levels of the original maximum; therefore the larger group depth is minimized.

## Complexity
Time is `O(n)` and output space is `O(n)`.
